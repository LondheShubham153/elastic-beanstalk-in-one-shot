# 12. Wrap-up

## What you covered

1. Elastic Beanstalk is a powerful PaaS. You bring code or a container image, and AWS runs the environment.
2. Project 1 deployed a store from a Docker Hub image with one small file.
3. Chapters 5 to 8 covered configuration, scaling, deployment strategies and health.
4. Cluster Mode ran the same image as a managed service. Project 2 used it with an RDS database.
5. Old PHP, Java or .NET apps can move over as they are, until their platform branch retires.
6. Project 3 put a GitHub Actions pipeline in front of the deploy.

## Before you finish

- Delete everything you created. The checklist is in [14-cleanup-and-cost.md](14-cleanup-and-cost.md).
- Standard Mode is Free Tier eligible for new AWS accounts. Cluster Mode is not.

## Build on Elastic Beanstalk

There is a hackathon called Build on Elastic Beanstalk. Build something on Elastic Beanstalk and post it on LinkedIn, tagging AWS and saying what you built. Check the video description for the current rules and dates. Share what you built in [Community Projects](../community/README.md) with a screenshot of the running app and a link to your repo.
